Open-source projects

Each repo has a reproducible evaluation on held-out data, a baseline to compare against, and an honest list of limits.

  • Document Capture

    Python, RapidOCR, pdfplumber, FastAPI

    Upload a receipt photo, invoice PDF or scan and get clean fields back, fully offline. Every value cites the page and bounding box it came from, and anything doubtful goes to a person for review instead of being guessed. Evaluated on the held-out CORD receipt benchmark

  • Lane-Drift Monitor

    Python, OpenCV, FastAPI

    Turns dashcam video into the car’s position in its lane, in metres, and flags lane departures for driver-safety review. Runs on a single CPU core with no GPU. Departure recall up from 0.00 to 0.94–1.00 against a per-frame baseline, at about 100 FPS

  • Urdu Scene Text Detection

    PyTorch, OpenCV, MS thesis

    Finds Urdu text of any shape on shop signs, banners and walls. A boundary model with graph convolutions and a Bi-LSTM refines a polygon until it hugs the curved text. F-score 0.76, against 0.50 for Faster R-CNN and 0.46 for YOLOv5

  • Computer Vision Fundamentals

    NumPy, OpenCV, PyTorch

    Ten classic algorithms written from first principles, each with a demo and a short write-up: Canny, Harris corners, camera calibration, rectification, a CNN with hand-written backpropagation, and graph convolutions. Normalised 8-point algorithm cut epipolar error from 8.72 to 0.25 px

Professional work

Built for employers and clients. The code is under NDA, so these are descriptions only.

  • Property map analysis

    Xosoft Technologies

    Reads scanned real-estate maps. Detection and segmentation models find plots and boundaries, and a Qwen3-VL agent decides when to call OCR, geometry checks or visual reasoning to settle ambiguous corners. Output is GeoJSON for GIS systems. 19K+ images at over 90% accuracy, with 95% less manual annotation

  • Real-estate price forecasting

    Xosoft Technologies

    Forecasts Dubai property prices from 1.4M+ Dubai Land Department transactions. Market regimes come from a Markov switching model, encodings are leakage-safe, and every model is tested on a later year it never saw.

  • Early fall detection

    Freelance client work

    Spots falls in surveillance video as early as possible. Skeleton movement, body action and scene context are fused in a multi-stage LSTM and compared with the original ST-GCN model.

What I’m building now

An agent on top of Document Capture that answers questions across many documents, such as “How much did we spend with this vendor in March?” It runs on open-weight models (Qwen3) through an MCP server, does all arithmetic in code rather than in the model, and cites the page behind every number.
